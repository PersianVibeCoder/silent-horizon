# Silent Horizon + Quiet Line · v1.0.0

A complete Cinnamon desktop setup with illustrated weather, a live horizon panorama, an elegant clock, animated glass card edges and Now Playing in the taskbar.

Download **silent-horizon.zip**, extract it, open the extracted folder in a terminal and run:

```bash
bash install.sh
```

The ZIP includes the applet, desklets, Gemini Blue wallpaper and fonts. The installer can install dependencies, backs up affected files and desktop settings, and prints a restore command. The default full layout replaces the panel and wallpaper; use `--layout widgets` to keep them.

After installing, log out and back in, then right-click Weather → Configure to set your own location. New settings start at latitude 0, longitude 0, elevation 0 and a blank label.

**Platform:** built on Linux Mint 22.3 / Cinnamon. Other Cinnamon distributions are not yet verified. Installer checks cover fresh installation, repeated installation, restoring a backup, failure rollback and zero-coordinate defaults. This first release has not yet been tested in a separate clean-machine graphical session.

**Preview:** the creator's 40-second, 1080p60 presentation, with its soundtrack retained and location-bearing visuals replaced by demonstration data at 0°, 0°. The video shows weather changes, accelerated sky motion, a close-up of the looping glow, expanded and collapsed cards, and the taskbar player.

**Files:**

- `silent-horizon.zip` — complete installation package.
