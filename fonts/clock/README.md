# Fixed clock faces

Static instances of the included OFL fonts, renamed to avoid collisions with system font versions:

- Silent Horizon Lead: Work Sans Light, weight 300.
- Silent Horizon Time: Work Sans Thin, weight 100.
- Silent Horizon Today: Baskervville Italic, weight 400.
- Silent Horizon Date: Inter Regular, weight 400, default optical size.

These derivatives remain under SIL Open Font License 1.1; the upstream copyright and license records remain embedded. See the license files beside them. Rebuild with `python3 scripts/build-clock-fonts.py` after installing fonttools for development only.
